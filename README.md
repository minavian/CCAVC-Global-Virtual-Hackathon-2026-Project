# CCAVC-Global-Virtual-Hackathon-2026-Project

## Hackathon delivery plan

Target completion on Day 3 and finish by the end of Day 4. Use GitHub issues to track owners and what each task must deliver.

- **Day 1.** Agree on the scope and stack, assign owners, and get the main website flow working end to end.
- **Day 2.** Complete and test the essential pages. Review progress as a team and prioritize blockers and demo-critical fixes.
- **Day 3.** Finish integration and verify the complete website. Use Day 4 if needed to resolve blockers and finish delivery.
- **Final 12 hours.** Freeze features, fix blockers, run a final end-to-end check, deploy, rehearse the demo, and record a backup video.
